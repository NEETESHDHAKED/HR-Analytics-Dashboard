# HR Analytics Dashboard | Power BI

## 📌 Overview
An interactive HR Analytics Dashboard built with Power BI to analyze employee attrition, department-wise performance, and workforce trends.

This project helps HR teams to take data-driven decisions to reduce attrition and improve employee satisfaction.

## 📂 Dataset
- `HR_Analytics.xlsx` - Contains employee data like Age, Attrition, Department, Salary, Satisfaction etc.

## 🛠️ Tools Used
- Power BI Desktop
- Power Query
- DAX

## 🔍 Key Insights
- Attrition rate is highest in Sales department
- Employees with low job satisfaction are more likely to leave
- R&D department has highest employee retention
